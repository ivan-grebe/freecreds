Privacy

FreeCreds has no user accounts and does not intentionally store student profiles. Search choices are sent to the hosting service as request parameters so results can be returned.

Analytics and hosting

The site uses Cloudflare Web Analytics. Cloudflare and the hosting platform may process request metadata such as IP address, user agent, requested path, timing, and coarse location under their policies and the deployment owner's settings.

Browser storage and external links

FreeCreds stores only the light or dark theme preference in browser local storage. College schedule and source links open third-party sites with their own privacy practices.
