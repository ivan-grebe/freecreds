# Privacy

FreeCreds does not currently provide user accounts or intentionally store
student profiles. Search choices are sent as request parameters to the hosting
service so results can be returned.

The deployed site includes Cloudflare Web Analytics. Cloudflare and the
hosting platform may process request metadata such as IP address, user agent,
requested path, timing, and coarse location according to the deployment
owner's Cloudflare configuration and policies.

The site stores only the light/dark theme preference in browser local storage.
Links to college schedules and source services lead to third-party sites with
their own privacy practices.

Before a public launch, the owner should verify analytics settings, log and
cache retention, access controls, and whether a consent notice is required in
the jurisdictions served.
